# Weekly operator prompt

Run this every Monday. It does not post, email strangers, or spend money.

1. Open Billfold archive. Count documents saved last week. That is activation, not revenue.
2. Check Stripe Payment Links for new payments. Email the current Pro key to each payer if it was not on the receipt.
3. Check Chrome Web Store stats for DomainMeter: installs, uninstalls, reviews. Reply to every review.
4. If installs are flat, change only the store subtitle and the first screenshot caption. Do not rebuild the product.
5. Export DomainMeter CSV and send yourself one invoice for your own tracked time, so the demo PDF stays current for the landing page.

Stop if a step needs a password, a new paid ad account, or messaging people who did not ask.
